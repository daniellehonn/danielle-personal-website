[ 01 ] OVERVIEW

The Problem

Vision models were improving fast and impossible to compare. General benchmarks measure general ability, which tells you very little about whether a model can read an ecommerce listing or a legal document — and running the same test across several models meant wiring each one up by hand.

What I Built

A benchmark built around three goals: a test suite with an industry focus rather than an academic one, a way to run the same tests against a list of models simultaneously, and an LLM evaluating the results to assign quality scores.

It covers the tasks vision models are actually asked to do — question answering, object detection, image-to-text description, counting, and generation — with Llava served through Cloudflare Workers AI.

Outcome

Deployed serverless on Cloudflare with a Svelte interface, so the suite runs as a usable demo rather than a script — anyone can run the comparison instead of reading someone else's summary of it.
