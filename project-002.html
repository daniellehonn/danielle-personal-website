[ 01 ] OVERVIEW

The Problem

Most of the knowledge worth asking an LLM about is locked in formats it can't read well — PDFs, scanned documents, transcripts. The text is there, but the structure that makes it meaningful (headers, tables, formulas, forms) is lost the moment you extract it naively, and a model given flattened output answers badly or not at all.

ContextForce was founded on that gap: the market needed genuinely accurate data extraction for AI applications, and PDFs were where existing tools failed hardest.

What I Built

An API demo that ingests three messy input types — webpages, PDFs and YouTube transcripts — and parses each into structured data on the far side.

Parsed content is embedded with HuggingFace and indexed in Pinecone, which turns the corpus into something searchable by meaning rather than keyword. A semantic search retrieves the passages closest to a query and hands them to the model as context — the retrieval half of RAG.

The demo runs on Streamlit and is model-agnostic by design: the same retrieved context can be routed to OpenAI, Claude, Gemini or Groq — or to a Llama model served locally through Ollama — so the pipeline isn't bet on a single provider.

Outcome

Showcased enterprise legal-tech applications to LegalZoom's Head of Data, positioning the prototype as a foundation for AI-driven knowledge management systems.
